# Security policy

Report vulnerabilities through the repository's **Security → Report a vulnerability** form rather than a public issue. Include the affected version, a minimal reproduction and impact. Do not include credentials or article bodies you cannot share. If private reporting is unavailable, use a private contact listed on the [maintainer's GitHub profile](https://github.com/octo-gone).

Security fixes target the latest release. Ordinary extraction disagreements and model errors belong in the issue forms.
